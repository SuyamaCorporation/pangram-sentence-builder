# Pangram Sentence Builder & Checker
26文字全てを含む「パングラム」を作成するインタラクティブなジェネレーター。
## Features
- リアルタイムで26文字の使用状況を色分け表示（赤=未使用 / 緑=使用済み）
- 残り文字数カウンターをリアルタイム更新
- パングラム完成時に絵文字アニメーションでお祝い
- 有名パングラム8例をサイドバーに表示（クリックで入力フィールドに挿入）
- 単語数・文字数の統計表示
## Usage
テキストエリアに文を入力すると使用済み文字が緑に変わる。26文字全て使うとパングラム達成！サイドバーの例文をクリックして学習することもできる。
